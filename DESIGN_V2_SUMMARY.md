## 🎨 Variables CSS Principales

```css
/* Couleurs brand */
--brand-primary: #059669
--brand-secondary: #0F766E
--brand-gradient: linear-gradient(135deg, #059669 0%, #0F766E 100%)

/* Ombres */
--shadow-sm: 0 2px 8px rgba(15, 23, 42, 0.04)
--shadow-md: 0 8px 24px rgba(15, 23, 42, 0.08)
--shadow-lg: 0 20px 40px rgba(15, 23, 42, 0.12)
--shadow-glow: 0 0 40px rgba(5, 150, 105, 0.3)

/* Rayons */
--radius-sm: 8px
--radius-md: 12px
--radius-lg: 16px
--radius-xl: 24px

/* Transitions */
--transition-fast: 150ms cubic-bezier(0.4, 0, 0.2, 1)
--transition-base: 250ms cubic-bezier(0.4, 0, 0.2, 1)
--transition-slow: 400ms cubic-bezier(0.4, 0, 0.2, 1)
```

## 📝 Maintenance

### Facilité de mise à jour

Grâce aux **variables CSS**, vous pouvez facilement :
- Changer les couleurs en modifiant `--brand-primary`
- Ajuster les espacements via `--space-*`
- Modifier les rayons avec `--radius-*`
- Tweaker les transitions avec `--transition-*`

### Extensibilité

Le design system est **modulaire** :
- Nouveaux composants s'intègrent facilement
- Classes utilitaires réutilisables
- JavaScript découplé (event delegation)
- CSS organisé par sections
