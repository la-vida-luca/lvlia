# JSON-LD Fermes Urbaines

- Inclure ces fichiers via `<script type="application/ld+json">` en les important côté serveur ou en build statique.
- `organization.json` et `localbusiness.json` sont à placer sur toutes les pages.
- `product.json` sur `/micro-serre-connectee/`.
- `faq.json` sur les pages avec la FAQ globale (pilier, pro, etc.).
- `article-template.json` sert de base pour les futurs contenus de blog.
