# Scripts d'automatisation

- `update-sitemap.js` : ajoute les nouvelles URLs dans `sitemap.xml` existant ou crée `addons/sitemap.xml` si absent. Requiert Node 18+, `jsdom` (`npm install jsdom`).
- `robots-append.txt` : instructions à ajouter manuellement dans `robots.txt` pour référencer la sitemap additionnelle.
