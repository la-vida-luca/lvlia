This directory contains photos used in the project.

Please place relevant images here. Each photo should be named using the following convention:

    IMG_<unique_number>.jpg

For example: IMG_6799.jpg

The photos should be related to the project's subject matter (e.g., micro-serre LVLIA setups, equipment, results).

To list the photos in this directory, use the following command in your terminal:

    ls *.jpg

Please update this README if you add new naming conventions or requirements.
